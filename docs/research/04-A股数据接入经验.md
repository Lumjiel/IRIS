# Research: A 股投研/爬虫开源项目接入 AKShare 与东方财富数据的工程细节

## Summary
AKShare 是对东财/新浪公开接口的薄封装，真实项目最大坑是**上游反爬/改版→全接口连锁失效**：东财对 `push2.eastmoney.com` 收紧风控后，AKShare 被迫把 39 个文件批量切到延时域名 `push2delay.eastmoney.com`，`stock_zh_a_hist` 等接口频繁触发 IP 封禁。mcp-eastmoney(27dream) 吃透了这个教训——只用东财免费延时接口（约 15 分钟延迟），5 个 Tool 源码可读，是简历项目"合规+可跑通"的极佳参考。缓存是刚需：社区最佳实践 = 内存+SQLite+交易日感知失效+增量更新，QuantDB 实测重复请求 ~1247ms→~18ms。

## Findings（要点，全文见交付文件）
1. **AKShare 的坑**（GitHub issue 一手证据）：封 IP/RemoteDisconnected（#6148/#6092/#6100/#6217，官方定性"东财反制，与 AK 无关"）；`push2` 域名空响应→官方 39 文件批量迁移至 `push2delay`（#7230/#7098）；`code_id_map_em_dict` 变动引发 KeyError、需升级+用户自换映射（#5646）；字段名/数量变化导致解析崩（#5777/#7250、TradingAgents-CN #692）；北向资金因上游停公布永久 NaN（#7315）。
2. **mcp-eastmoney**：封装 3 个东财域名 5 个 Tool——`push2delay`（quote/clist 资金流）、`push2his`（K 线 klt/fqt）、`searchadapter`（搜索）；踩坑处理：`f152` 小数位修正、`'-'`停牌兜底、Referer 头；实测唯一坑是 push2delay 偶发抽风需几秒重试；v0.2.0 新增北向/涨停池/技术指标/港美股。项目小（星数个位数），参考实现而非生产级。
3. **缓存最佳实践**：QuantDB 三层缓存（内存→SQLite WAL→AKShare）+ 交易日感知失效 + 增量拉取缺失区间，98.6% 提速；mqzkim/trading 的 SQLite+TTL 最小实现；官方社区推荐"spot 快照+本地维护历史"替代重复全量拉取（#6100）；TTL 分档（实时 5min/日线 24h/历史永久）。
4. **合规标注**：mcp-eastmoney README 措辞（延时 ~15 分钟/仅供研究/非投资建议/控制频率）可直接抄；ashare-lake 合规文档范本（许可 vs 数据版权边界、口径声明、不提供再分发）；investool/OpenStockData 免责模板；简历写"接入东财公开延时接口"比"爬取实时数据"有说服力得多。
