# 早停相似度分词对照实验（tfidf_tokenizer_experiment）

- 时间：2026-11-19（goal round 8 归档；文本与场景设计同日定稿）
- 动机：`reviewer.py:58-63` 的 cosine 早停用裸 `TfidfVectorizer()`，默认
  `token_pattern (?u)\b\w\w+\b` 按空白/标点切块——中文长句整段成一个 token。
  本实验量化「默认实现全盲于小数位修订」，并对照 char n-gram / jieba 两个候选的阈值重标压力。
- 方法：镜像 `reviewer.py:58-63` 算法（两文本联合 `fit_transform` 后取行间 cosine），
  同一段研报文本 4 个修订场景 × 3 种分词方案。
- 复现：`cd backend && .venv/bin/python eval/reports/tfidf_tokenizer_experiment.py`
- 环境：scikit-learn 1.7.2 / jieba 0.42.1（`backend/.venv`，2026-11-19 实跑）

## 实验文本

基准文本（贵州茅台三季报摘要，含数字事实 + 样板结构）：

> 本报告分析贵州茅台2024年三季报营收1207.76亿元，同比增长15.2%，合同负债维持高位，
> 渠道打款意愿积极。投资建议：维持买入评级，目标价1850元，建议关注高端白酒龙头。
> 风险提示：宏观消费复苏斜率不及预期，批价波动加大。

四个修订场景定义见 `tfidf_tokenizer_experiment.py` 的 `SCENARIOS`（S1 只改小数位 /
S2 改整数 / S3 同义改写两句 / S4 换行业换业务事实）。

## 结果（2026-11-19 实跑输出）

| 修订场景 | 默认(现状) | char_wb(2,4) | jieba |
|---|---|---|---|
| S1 只改小数位 15.2%→15.3% | **1.0000（全盲，触发早停）** | 0.9504 | 0.9804 |
| S2 改整数 1207.76→1215.42亿 | 0.7168 | 0.8933 | 0.9804 |
| S3 同义改写两句（典型修订编辑） | 0.6030 | 0.7827 | 0.9051 |
| S4 换一家公司（应判低相似） | 0.4148 | 0.5287 | 0.7385 |

默认实现词表样例（排序后前 10，可见「一个标点分隔的长句 = 一个 token」）：

```
['76亿元', '合同负债维持高位', '同比增长15', '宏观消费复苏斜率不及预期',
 '建议关注高端白酒龙头', '批价波动加大', '投资建议',
 '本报告分析贵州茅台2024年三季报营收1207', '渠道打款意愿积极', '目标价1850元']
```

## 结论

1. **默认实现全盲于小数位修订**：`15.2%` 被 token_pattern 切成「同比增长15」（整段保留）
   + `2`（单词字符，`\w\w+` 要求 ≥2 词字符，直接丢弃）——把 2 改成 3 词表一个字符都不变，
   cosine 精确 = 1.0000，> 0.95 阈值直接早停，而路由顺序里早停判定先于 review 裁决
   （`graph.py` should_continue），质量裁决根本不跑。
2. **char_wb(2,4)**：小数位立刻可见（0.9504），但整体水位抬高（S3 0.603→0.783、
   S4 0.415→0.529），0.95 必须随之重标（可设阈区间：S1 0.950 与 S3 0.783 之间）。
3. **jieba**：粒度语义最对，但水位抬得最狠（S4 0.415→0.739），高低场景分差从默认的
   0.585（1.000−0.415）收窄到 0.241（0.980−0.739）≈ **2.4 倍**，阈值重标压力最大。
4. **接法陷阱（实验过程中抓到的额外事实）**：jieba 必须以
   `TfidfVectorizer(tokenizer=jieba.lcut, token_pattern=None)` 直传；
   若把 jieba 切词结果拼回空格分隔字符串再过默认向量化器，`15.2%` 会被二次切分、
   `2%` 只含一个词字符被丢弃——**小数位盲区原样保留（cosine 仍精确 = 1.0）**，
   jieba 等于白装。
5. 修复排序（结合三候选代价）：char n-gram + 阈值重标 > jieba > embedding
   （embedding 对「复读机检测」目标不对位：改数字没改观点的两版报告在语义空间里本来就极近）。
